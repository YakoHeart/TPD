# WordCount Distribuído - Programação Paralela e Concorrente

## Pré-requisitos
- Python 3.6 ou superior (padrão em qualquer sistema)

## Como executar
1. Baixe o vscode
2. Baixe o python
3. Entre no vs code vai em file depois open a folder
4. Selecione a pasta trabalho_distribuida
5. Crie alguns arquivos .txt grandes para teste, deixei alguns já criados para teste.
6. Abra o terminal e digite "python wordcount.py texto1.txt texto2.txt", sem as aspas.
