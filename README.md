WordCount Distribuído - Programação Paralela e Concorrente
Pré-requisitos
Python 3.6 ou superior (padrão em qualquer sistema)
Como executar
Baixe o vscode
Baixe o python
Entre no vs code vai em file depois open a folder
Selecione a pasta trabalho_distribuida
Crie alguns arquivos .txt grandes para teste, deixei alguns já criados para teste.
Abra o terminal e digite "python wordcount.py texto1.txt texto2.txt", sem as aspas.
